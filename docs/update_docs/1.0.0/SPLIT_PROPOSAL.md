# 1.0.0 拆包与复用建议（草案 · 待确认）

> 对应你的想法：减法（长柄 / 多盾）+ 拆成 3 模组。  
> **不改代码**，只标归属与耦合，方便你拍板。

---

## 一、建议裁剪（减法）

| 项 | 现状 | 建议 | 理由 |
|---|---|---|---|
| `sword_long` | 代码：双手清副手 | **移出默认锻造 / 或整段删除** | 「多余长柄」；双手规则可留给格挡模组或以后再加 |
| `axe_short` / `axe_long`（0.0.4） | 仅文档 | **取消 0.0.4** | 同左，避免再堆档案 |
| `light_shield` | 独立物品 | **移除**（若只要原版盾或纯剑挡） | 「去掉多的两种盾」之一 |
| 原版盾作重盾配置 | 创造栏 + `HEAVY_SHIELD` 配置 | **移除模组侧重盾逻辑** | 同上；格挡模组可只做**剑挡** |
| 钢工具快捷 `steel_*` shaped | 并行验证 | 锻造大改前可 **暂留测试** 或并入 2.1 | 与锻造链重复入口 |

确认时请明确：减法是 **删代码** 还是 **先从锻造产物表拿掉、物品保留**。

## 二、三模组拆分（目标形态）

### 2.1 武器拓展（Weapon Expansion）

**目的：** 新材料工具线，少打架原版成长。

| 纳入（复用） | 说明 |
|---|---|
| `emerald_*` / `redstone_*` / `lapis_*` | 已有物品与配方骨架；按你的规则改：绿宝石**单颗**，红石/青金石**块**（及新黑曜石） |
| 工具类继承 | 现多为 `*Item` + `ModToolMaterials`；可整理为「继承剑/镐/斧/铲/锄」清晰结构 |
| （可选）锐利度 + 磨刀石 | 若希望装饰工具也有钝/磨；否则锐利度可跟锻造或独立 |

| 新建 | 说明 |
|---|---|
| 黑曜石工具套 + 配方 | 全新 |
| 独立 mod id / 创造栏 | 如 `weapon_expansion` |

| 不纳入 | 说明 |
|---|---|
| 锻造模板/件/高炉槽 | → 2.3 |
| 格挡/双持/盾 | → 2.2 |

---

### 2.2 剑格挡（Sword Guard）

**目的：** 近战防御规则独立，可装在任意武器包上。

| 纳入（复用） | 说明 |
|---|---|
| `GuardService` / `GuardWindows` / `GuardProfile` | 剑挡核心 |
| `BLOCKS_ATTACKS` + 反打 mixin | 战斗钩子 |
| （可选）双持轮攻、双手清副手、弓弩空手 | 同属「手部规则」，可进 2.2 或拆更细 |
| （可选）`armor_class` 移速 | 偏生存平衡；可留主包或 2.2 |

| 裁剪倾向 | 说明 |
|---|---|
| 轻盾 / 重盾配置 | 按你的减法，默认 **不做盾线**，只保留剑挡 |
| 与 `forged_sword` 的硬编码挂接 | 改为：**数据组件 / tag「可格挡」**，2.3 或 2.1 给物品打标即可 |

---

### 2.3 锻造工艺（Forge Craft）— 大升级待你重写

**目的：** 现有锻造链作**零件库**；玩法规格你后续重开需求。

| 高复用价值 | 说明 |
|---|---|
| Early Heat（火堆、点燃槽、高炉岩浆、钢锭） | 热源基建，升级锻造多半仍要 |
| 模板 → 燃烧 → 冷却 → 零件 → 装柄 状态机 | 可改流程，组件形态可留 |
| `ForgeMetal` / `TemplateFamily` / stage | 枚举可扩成数据驱动 |
| 高炉模板槽 Mixin + UI 槽位 | 少见基础设施 |
| 件外观 CMD / pixel_drawer 脚本 | 美术管线可留 |
| `WeightData` → 攻速 | 若新锻造仍「用量影响手感」 |

| 低优先级 / 易废 | 说明 |
|---|---|
| 当前 12 张 3×3 模板图案 | 大改时可能整表重做 |
| `forged_*` 与格挡的耦合 | 应改为可选依赖 2.2 |
| 档案膨胀（长剑/长短斧） | 与减法一致，先收紧 |

**依赖建议：** 2.3 **软依赖** 2.2（有则挂格挡）；2.1 **不依赖** 2.3（纯合成工具）。

## 三、耦合与拆包注意

```
今日单模组 SurvivalMod
  ├─ heat ──────────────► 宜归 2.3
  ├─ forge ─────────────► 宜归 2.3（大改）
  ├─ tools/sharpness ───► 2.1 与/或 2.3（需定归属）
  ├─ combat ────────────► 宜归 2.2
  └─ emerald/redstone/lapis/steel ─► 宜归 2.1（钢是否进锻造另定）
```

| 问题 | 选项 |
|---|---|
| 组件命名空间 | 共用 API 模组 vs 各模组自有 id（存档不兼容） |
| `forged_*` 注册方 | 2.3 产出；属性/格挡由组件声明 |
| 锐利度归属 | A 只装饰无钝 / B 全局工具层 / C 仅锻打件 |
| Early Heat 是否单独第 4 包 | 现建议先塞进 2.3，避免过碎 |
