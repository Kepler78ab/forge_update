# 1.0.0 任务一：拆出「武器拓展」与「剑格挡」

> **状态：已确认，按本文实施。**  
> 2.3 锻造暂留本仓库根工程；本任务拆出 2.1 + 2.2。

---

## 〇、已确认决策（2026-09-28）

| 项 | 决定 |
|---|---|
| 工程 | **方案 A** Gradle 多模块 |
| 钢工具 | **进武器拓展**；合成材料为 **铁块** |
| 武器拓展盔甲 | **要**：复用原版盔甲类；贴图用 pixel_drawer **换色**（同工具材质替换思路） |
| 绿/红/青工具 | 进拓展（绿宝石单颗、红石/青金石块 — 维持现状） |
| 黑曜石 | 下一批（本任务不阻塞） |
| 锐利度 + 磨刀石 | **留锻造** |
| 剑格挡 | **纯剑挡**；对 **一切继承剑类（`SwordItem`）** 的物品生效 |
| 剑 + 副手盾 | 走 **原版盾格挡逻辑**（不叠剑挡窗） |
| 双持 | **进格挡包** |
| 双手 + 弓弩规则 | **进格挡包** |
| `armor_class` | **留锻造** |
| 轻盾 / 重盾模组逻辑 | **不要**（不迁入格挡包；主包删除/停用） |
| 主包对格挡 | **不依赖**（无 depends / suggests）；格挡靠类型判定，锻剑无需挂组件 |

关系：

```
weapon_expansion  ──独立──► 无依赖
sword_guard       ──独立──► 无依赖（instanceof SwordItem + 手部规则）
attack_anime_fix（锻造）──独立──► 无依赖格挡；锐利度/磨刀石/armor_class/热源/锻造链
```

## 六、锻造工艺（2.3）模块边界 — 已约定

> **等你描述新锻造设计后再实现。**

| 原则 | 说明 |
|---|---|
| **只接管中间过程** | 新锻造工艺 = 模板→件→装柄等**锻造链本身**；不改写武器拓展 / 剑格挡 / 原版的合成表 |
| **不碰其他模组配方** | `weapon_expansion` 的绿/红/青/钢工具与盔甲配方独立；格挡无配方依赖 |
| **对外用接口/组件/tag** | 锻造成品若需锐利度、双手档案等，用本包组件或 tag 声明；格挡仍由 `sword_guard` 按剑类判定 |
| **可单独装卸** | 不装锻造时，拓展工具与剑格挡仍应可玩 |

现状根工程里的 Early Heat / 锐利度 / 磨刀石 / `armor_class` 是否并入新锻造包，等你设计文里一并定。
