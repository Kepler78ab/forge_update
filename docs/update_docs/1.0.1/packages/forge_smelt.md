# forge_craft · smelt（F2–F7）

| 项 | 说明 |
|---|---|
| 包名 | `…survival.smelt` + `…survival.forge`（模板/铸造件） |
| 引擎 | `SmeltEngine` |
| **材料表** | 内置默认 + `data/*/smelt_material/*.json` 覆盖/新增（热重载） |
| **颜色覆盖** | 内置 + `data/*/smelt_color_override/*.json` |
| **可熔炼表** | `data/*/smelt_input/*.json`；未登记→`impurity`；`molten_metal`/`alloy_ingot` 按组件重熔 |
| **熔炼高炉 / 石漏斗** | 见前；漏出对接模板台 |
| **模板台** | 收熔融；画框放模板；**铸造**按钮 |
| **F6 铸造** | **无模板**→合金锭（1升）；**有模板**→燃烧件（耗升数按外形，模板已含棍） |
| **燃烧件** | 可当工具：火焰附加 I、伤害偏低；遇水→成品锻具 |
| **成品** | 硬度→伤害/耐久/锐利上限；颜色随合金染色 |
| **旧高炉模板槽** | **已移除**（F6） |

## 材料 JSON 示例

```json
{
  "id": "copper",
  "color": [200, 120, 60],
  "hardness": 3.0,
  "weight": 1.0,
  "category": "metal"
}
```

## 铸造耗升

| 外形 | 升 |
|---|---|
| 铲 | 1 |
| 剑 / 锄 | 2 |
| 长剑 / 斧 / 镐 | 3 |
| 盔 / 靴 / 腿 / 甲 | 5 / 4 / 7 / 8 |
| 无模板合金锭 | 1 |
