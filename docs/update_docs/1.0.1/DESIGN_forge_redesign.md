## 一、模块拆分（确认版）

```
tool_pressure（新·可选）     禁木石以外工具+非皮盔甲合成；耐久倍率（含甲）
weapon_expansion（已有）     绿/红/青/钢(/黑曜石)工具盔甲；钢×3/4、黑曜石×4/5 耐久
forge_craft（根工程演进）    熔炼高炉·石漏斗·模板台·熔融金属·模板·燃烧件→冷却→成品
sword_guard（已有）          不碰
tool_sharpness（下一批）     锋利独立包
```

| 模组 | 是否强制 | 说明 |
|---|---|---|
| `tool_pressure` | 否 | 可选；装上才「关闭原版中后期合成捷径」 |
| `forge_craft` | 主题核心 | 中间链 + 熔炼引擎 |
| `weapon_expansion` | 否 | 旁路合成；与锻造并行 |

## 二、锻造中间链（确认版流程）

```
[熔炼高炉]  ——开关开启时漏出熔融金属——►  [石漏斗]  ——漏入——►  [模板台]
  岩浆为燃烧物；内容物 bar≤64升              只收熔融；仅 bar           画框实体放模板
  放置物→并入成分                                                                  │
                                                                                   ├ 无模板 → 合金锭（仅可重熔）
                                                                                   └ 有模板 → 燃烧的 xxx（模板已含棍）
                                                                                              │
                                                                                              ▼
                                                                                    遇水/水锅冷却 → 最终武器
```

### 方块

| 方块 | 外观 | 行为 |
|---|---|---|
| 熔炼高炉 | 复用高炉模型/材质 | 仅岩浆桶作燃烧；UI：内容 bar + 放置槽 + 燃烧槽；**开关控制是否漏向漏斗** |
| 石漏斗 | 复用漏斗模型/材质 | 只接收熔融金属；UI 仅 bar；破坏掉落熔融金属物品 |
| 模板台 | 末地门框架感 + **画框实体** | 框内放模板；接石漏斗；铸造按钮出合金锭/燃烧件 |

### 物品 / 机制

| 项 | 说明 |
|---|---|
| 熔融金属 | 属性：升数、材质构成与比例；≤64 升；可反复重熔；只能放回熔炼高炉 |
| 合金锭 | 无模板时产出；颜色/成分由熔融决定；除重熔外无用 |
| 模板 | 石头 / 下界岩 / 砖 / 粘土构造；工具配方已含木棍 |
| 燃烧武器 → 冷却 | **保留**旧遇水冷却；燃烧件可作低伤工具且带火焰附加 I；冷却后为最终可用武器 |
| 属性化成品 | 颜色/硬度→耐久、重量、攻速由 `熔炼系统拓展.md` 引擎计算，不靠铜铁钢枚举 |

## 三、熔炼核心（自研 · 对照 `熔炼系统拓展.md`）

三层解耦，数据包驱动：

1. **材料定义** — color / hardness / weight / category / special  
2. **混合引擎** — Linear RGB 颜色；硬度 = 加权 + max 修正 + 杂质惩罚  
3. **输出映射** — 硬度区间等 → 显示名/物品类型；颜色 auto  

实现落在 `forge_craft` 内独立包名（如 `…smelt`），便于单测。
