# Roadmap — Survival Updated

机制向更新：优先改**规则与成长曲线**，不做重动画战斗模组。

基线：**1.21.11 Fabric** · 远期：**26.x+**

## 原则

- 一条机制解决一个生存痛点或成长空窗
- 尽量数据驱动（JSON / tag），少硬编码
- 先文档立项 → 再实现 → 再记入 CHANGELOG
