## [Unreleased]

### Added

- **0.0.7 装柄配方 + 金属分色**

  - 冷却/零件图标按铜·铁·钢分色；燃烧仍按档案热色
- **0.0.6 锻造件按模板外形**
  - 铸造件去柄剪影；CMD 见 0.0.7 扩展为金属后缀
  - 创造栏列出锻造件变体；冷却仍为右键水 / 水锅
- **0.0.5 模板改 3×3 工作台**
  - 12 张原版 shaped 配方产出锻造模板（组件 + `custom_model_data`）
  - 移除模板台方块 / UI / 配方；创造栏仍列出全部模板变体
- **0.0.3 材质与模型**
  - 火堆深色营火；磨刀石黑石轮
  - 轻盾 / 重盾暂用原版盾 3D 占位
  - 中甲/重甲物品栏贴图；重甲 humanoid 露脸+下巴包边
  - 创造栏补模板变体、盾、轻/中/重甲；规则 `creative-tab.mdc`
- 架构方案 Accepted：`features/early_craft_forge_guard.md`
- **一期 Early Heat（初版）**
  - 火堆（营火占位模型）、H 型木棍合成、类熔炉 UI（木燃料 / 食物与木制品）；火把右键点燃火堆
  - 熔炉 / 烟熏炉：点燃物槽（火把或岩浆桶）+ 燃料槽；无点燃物不开始燃烧
  - 高炉：仅岩浆桶可作燃料；钢锭高炉配方骨架（生铁 → 钢锭）
  - 打火石保持原版；取火器已移除

- **二期 Tools & Sharpness（初版）**
  - `su:sharpness` 数据组件 + 伤害/斧挖掘倍率；铜+出厂偏钝，磨刀石右键恢复
  - 锋利附魔折算为额外倍率；tooltip 显示锐利度
  - 木镐/斧/锄挖掘对齐木剑；石剑攻速下调；钻石工具合成禁用（空 tag 配方）
  - 钢工具（占钻石合成位）+ 绿宝石/红石块/青金石块装饰轻工具骨架
- **三期 Forge Pipeline（初版）**
  - 原版工作台 3×3 排模板（木板族 / 下界岩族 × 剑·长剑·斧·镐·铲·锄）→ 锻造模板
  - 高炉模板槽：有模板 + 铜/铁/钢 → 燃烧件（钢需下界岩族模板）；无模板仍出普通锭
  - 燃烧件点水/水锅冷却 → 右键工作台拆零件 → 零件+木棍装柄 → 磨刀石
  - 二期钢工具 shaped 配方暂保留（并行验证）
- **四期 Armor & Guard（初版）**
  - `armor_class`：皮/锁轻、铜铁金中、钻下重；穿戴件叠加移速惩罚
  - 剑右键格挡（完美/衰减/无效窗）+ 完美反打；双剑完美窗 ×2
  - 轻盾（快举、可反打）/ 原版大盾（持续格挡、无反打）
  - 双持单手剑轮流攻击；长剑模板 `sword_long` 双手清副手；弓/弩需对侧空手才能拉
- **材质（物品贴图初版）**
  - 钢系 / 锻打复用 / 绿宝石·红石·青金石装饰工具 / 锻造模板·锻造件·轻盾图标
  - 火堆 / 磨刀石方块世界模型见 0.0.3
- 基线 MC **1.21.11**；远期目标 **26.x+**
